# ПРОМПТ ДЛЯ СОЗДАНИЯ ВЕБ-СЕРВИСА GARAGE

## Роль и контекст
Ты — опытный full-stack разработчик с экспертизой в создании современных веб-приложений. Твоя задача — создать полноценный веб-сервис для автовладельцев под названием GARAGE.

## Описание проекта
GARAGE — это персонализированный хаб для автовладельцев, где пользователь добавляет свой автомобиль по VIN-номеру и получает доступ ко всем сервисам, адаптированным под его конкретную машину: запчасти, ремонт, страхование, учёт расходов, штрафы и сообщество владельцев.

Ключевой принцип: Весь контент и функционал персонализированы под автомобиль пользователя. Как только машина добавлена, сайт начинает работать в контексте этой машины.

---

## ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 1. Онбординг и добавление авто
- Поле ввода VIN или госномера на главной странице
- Анимация "сканирования" авто при вводе VIN (силуэт автомобиля собирается из частиц)
- Автоматическое получение данных авто по VIN (марка, модель, год, комплектация, двигатель)
- Показ "тизера" с инсайтами по авто до регистрации (типичные проблемы, отзывные кампании)
- Регистрация через SMS или соцсети (Яндекс, VK, Google) после получения данных
- Возможность добавить несколько автомобилей с переключением между ними

### 2. Дашборд "Мой гараж"
- Карточка автомобиля с SVG-визуализацией или качественным фото
- Индикаторы "здоровья" авто (двигатель, тормоза, масло) в виде прогресс-баров с цветовой кодировкой (зелёный/жёлтый/красный)
- Блок сводки: следующее ТО, штрафы, расход в месяц, срок полиса
- Быстрые действия: кнопки перехода в основные разделы
- Алерты: что нужно сделать срочно (просроченное ТО, истекающий полис)
- История обслуживания (таймлайн)

### 3. Дневник расходов (ключевая фича)
- Карточки статистики: всего за год, за месяц, стоимость 1 км, средний расход топлива
- Индикаторы изменения к прошлому периоду (↑/↓ с цветом)
- Круговая диаграмма расходов по категориям (топливо, ТО, страховка, ремонт, прочее) с суммой в центре
- Столбчатый график расходов по месяцам с тултипами при наведении
- Список последних записей с иконками категорий и цветовой кодировкой
- Фильтры по категориям
- Модальное окно добавления расхода:
  - 8 категорий с иконками (топливо, ТО, ремонт, страховка, налог, мойка, парковка, тюнинг)
  - Поля: описание, сумма, дата, пробег, литры (для топлива), место/примечание
  - Новая запись появляется сверху списка с анимацией
- Автоматический расчёт стоимости 1 км и среднего расхода

### 4. Подбор запчастей
- Интерактивная схема автомобиля (SVG) с кликабельными узлами
- Подбор запчастей строго по VIN
- Сравнение цен в одной карточке: оригинал, аналоги, б/у
- Бейджи для типов (Оригинал — зелёный, Аналог — жёлтый, Б/У — синий)
- Интеграция с каталогами запчастей (Exist, Autodoc API)

### 5. Дополнительные разделы (для версии 1.0-2.0)
- Колёса и шины: подбор по размеру авто, 3D-примерка дисков, калькулятор расхода
- Ремонт и ТО: карта дилеров и СТО рядом, калькулятор стоимости ТО, онлайн-запись
- Страхование: калькулятор ОСАГО/КАСКО, сравнение предложений, покупка в 1 клик
- Штрафы: проверка и оплата по госномеру/СТС
- Сообщество: форум/блог по модели автомобиля, бортжурналы

## ДИЗАЙН-СИСТЕМА (Modern Card UI)

### Цветовая палитра
- Фон основной: #0A0E1A (глубокий тёмно-синий, не чёрный)
- Фон карточек: #141824
- Фон третичный: #1C2130
- Границы: #2A2F3E (тонкие, 1px)
- Текст основной: #FFFFFF
- Текст вторичный: #8B92A8
- Текст третичный: #5A6178
- Акцент основной: #0066FF (электрический синий)
- Акцент светлый: #00D6FF
- Успех/Норма: #00D68F (зелёный)
- Внимание: #FFB800 (жёлтый)
- Опасность: #FF3B5C (красный)
- Премиум: #8B5CF6 (фиолетовый)
- Топливо: #FF6B35 (оранжевый)
- Градиент CTA: linear-gradient(135deg, #0066FF, #00D6FF)

### Типографика
- Заголовки: Manrope или Unbounded (геометричный, современный, технологичный)
- Основной текст: Inter (идеальная читаемость)
- Моноширинный (VIN, артикулы, цифры): JetBrains Mono
- H1: 48px/700, H2: 32px/600, H3: 20px/600, Body: 16px/400, Caption: 12px/400

### Стилистика
- Тёмная тема по умолчанию (как "ночной кокпит")
- Карточки с большими скруглениями (20-28px)
- Мягкие тени: shadow-sm (0 2px 8px), shadow-md (0 8px 24px), shadow-lg (0 16px 48px)
- Эффект свечения при hover: box-shadow + glow
- Градиенты для акцентных кнопок
- HUD-элементы (тонкие линии, угловые скобки, моноширинные цифры)
- Glassmorphism для header (backdrop-filter: blur(20px))
- Плавные анимации: fade-in, slide-up (150-300ms, cubic-bezier(0.4, 0, 0.2, 1))
- Skeleton screens для загрузки (с синим оттенком, не серые)
- Лёгкий шум (noise) на фонах для матовости
- Прогресс-бары с анимацией shimmer

### Иконки
- Стиль: тонкие линии (1.5px), скруглённые углы
- Библиотека: Lucide React или Phosphor Icons
- Цвет: вторичный текст, при hover — акцент

### Визуальные метафоры
- Кокпит спорткара — приборная панель, HUD-элементы
- Технический чертёж — тонкие линии, схемы
- Цифровой гараж — тёмное пространство с акцентной подсветкой

## СТРУКТУРА СТРАНИЦ

### 1. Главная (публичная)
- Header: логотип, навигация, кнопка входа
- Hero-блок: заголовок, подзаголовок, поле ввода VIN/госномера с кнопкой "Проверить"
- Сетка категорий услуг (6 карточек): Запчасти, Дневник расходов, Колёса, Ремонт, Страхование, Сообщество
- Блок "Как это работает" (3 шага)
- Footer

### 2. Дашборд (после авторизации)
- Header с переключателем авто (dropdown)
- Приветствие пользователя
- Карточка авто (SVG + индикаторы здоровья) + блок сводки (2 колонки)
- Быстрые действия (сетка 4 кнопки)
- Алерты "Что нужно сейчас"
- История обслуживания

### 3. Дневник расходов
- Header с кнопкой "Добавить расход"
- Статистика (4 карточки в сетке)
- Графики (2 колонки): круговая диаграмма + столбчатый график
- Список расходов с фильтрами
- Модальное окно добавления расхода

### 4. Запчасти
- Header с VIN авто
- 2 колонки: интерактивная SVG-схема авто | список запчастей с ценами
- Карточки запчастей с вариантами (оригинал/аналог/б/у)

## ТЕХНИЧЕСКИЙ СТЕК

### Frontend
- Framework: Next.js 14+ (App Router)
- UI: React 18+
- Стилизация: Tailwind CSS
- Анимации: Framer Motion
- Иконки: Lucide React
- Графики: Recharts
- Формы: React Hook Form + Zod
- State management: Zustand

### Backend
- Runtime: Next.js API Routes
- База данных: PostgreSQL
- ORM: Prisma
- Аутентификация: NextAuth.js (SMS, Google, VK)
- Кэш: Redis

### Внешние API
- VIN-декодер: NHTSA API или VinDecoder
- Запчасти: Exist/Autodoc партнёрские API
- Штрафы: ГИБДД API
- Страховки: агрегаторы API

### Инфраструктура
- Хостинг: Vercel (frontend) + Railway (backend)
- CDN: Cloudflare
- Мониторинг: Sentry
- Аналитика: Yandex Metrika
